# Demo 40: Ghost Blogging Platform

Modern publishing platform for professional bloggers.

## Features

- Clean, minimal design
- Built-in membership and subscriptions
- SEO optimized
- MySQL backend (Node.js)

## Default Setup

After installation, visit `/ghost` to create your admin account.

## Requirements

- MySQL addon
- Docker support
