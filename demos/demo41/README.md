# Demo 41: Piwigo Photo Gallery

Self-hosted photo management and gallery software.

## Features

- Photo album management
- Plugin system for extensions
- Multiple user support
- MySQL backend

## Default Setup

After deployment, visit the URL to complete the installation wizard.
Use the MySQL credentials from the DATABASE_URL environment variable.

## Requirements

- MySQL addon
- Docker support
