# Lessons Learned

**Updated**: 2026-10-29, adding the October 2026 audit's lessons to ten topic files, then the lessons from the review of its fixes to seven. 2026-09-08: The internal `lessons-learned.md` (December 2025 to April 2026) was merged into these files and retired; the numbered inline lessons that used to sit below this index moved into their topic files. Three files are new: `dependency-injection.md`, `docker-apps-and-images.md`, `development-process.md`.

**Convention:** group each new lesson into the thematically closest file below; create a new file if none fits. Keep this `00README.md` an index; the files are canonical.

## Topic deep dives

- [`app-deploy-runtime-model.md`](./app-deploy-runtime-model.md): how an app behaves config → build → run: RPC session isolation, deploy-vs-redeploy state transitions, the build artifact as the runtime contract, one environment core for workers and one-off processes, build hooks versus workers, port listening as the truth, 502s, eventual consistency, HOST_NAME/proxy semantics; then October 2026: every builder declares itself, several toolchains make one artifact, an optional session that hid a caller, plugin precedence made explicit, a gated field with no default, a failure record that follows what happened.
- [`async-thread-boundaries.md`](./async-thread-boundaries.md): cross-thread `asyncio` pitfalls (the "every deploy takes 30s" bug) and choosing the right primitive per producer/consumer boundary; October 2026: every handler that does I/O runs off the single event loop.
- [`cli-ergonomics.md`](./cli-ergonomics.md): evolving the CLI command surface safely (rename via alias, deprecate by hiding), clear help and error messages, the client-side cache and registry copies that rot, structure over scraped prose, secrets out of argv; then September 2026: validate before you confirm, global flags stop at a wrapped program, one settings object behind every ssh; October 2026: declared flags only, the platform's own hints and scripts as argv, a typed positional used or refused, a hidden alias that took a secret. (ADR 036)
- [`database-addon-portability.md`](./database-addon-portability.md): PostgreSQL, MySQL and Redis connectivity (localhost vs 127.0.0.1, host matching, Docker-bridge rewrites), per-framework env-var mapping, reserved identifier prefixes, identifiers that collide after the service rewrites them, across native and Docker deployment.
- [`dependency-injection.md`](./dependency-injection.md): when a class is a DI service and when it is data, APP versus REQUEST scope, sessions as iterators, plugin providers, testing against a real container, Dishka's coroutine-only `@inject`, one table for a registry; October 2026: the request scope outlives a streamed response, an import that read the live config. (ADR 028)
- [`deployment-diagnostics.md`](./deployment-diagnostics.md): making deployment failures actionable, plus the checks that must not lie: timeouts that diagnose, specific error patterns, the structured `Diagnosis`, logs collected before cleanup, a timing ceiling that is a false failure under load, disk exhaustion; October 2026: a probe that could not ask must not answer "absent", teardown leftovers, re-wrapped exceptions, a status badge bound to nothing.
- [`development-process.md`](./development-process.md): search before building, inherited code as a claim, a systemic fix shipped to every sibling, entry points audited together, signature changes grepped across the workspace, one's own duplication reviewed before the commit, a fallback's premise read before it is kept or replaced, a rule nobody can explain traced, then enforced or deleted.
- [`docker-apps-and-images.md`](./docker-apps-and-images.md): build from source on the server's base, architecture and language-version constraints, Compose recreation, framework host checks, `COPY` permissions, images that cannot be automated, logging what a check expected, ran and got; October 2026: containers selected by exact identity, a step whose failure the next check covers.
- [`documentation-and-publication.md`](./documentation-and-publication.md): the public/private tree boundary, documentation as a claim that rots, advertised numbers needing a gate, generated-vs-source trees, suspecting the renderer before the source, errors that name their input, executable tutorials, undecided alternatives, what a report review pass finds.
- [`e2e-test-infrastructure.md`](./e2e-test-infrastructure.md): building and running the E2E suite. September 2026 added these: a skip is a hole, the sanitized Docker config that lost its context, two sessions on one machine, an image that carries what a real install carries, and tests that must not write the developer's known_hosts.
- [`multi-distribution-support.md`](./multi-distribution-support.md): Debian / Red Hat / Fedora parity patterns, init-system detection, the bundler's name collisions, an installer that starts what it installs and aborts on a feature it could not provide; October 2026: the bundle's minimum Python, secrets reused only when absent, reconcile steps without early returns, `check=True` on every branch.
- [`native-apps-caveats.md`](./native-apps-caveats.md): caveats specific to `builder = "local"` native deployments, PHP and Elixir included.
- [`nix-packaging.md`](./nix-packaging.md): gotchas from the Nix integration effort, wrapper-script traps, pre-built binaries as a shortcut, and the closure guard that gated on the wrong field.
- [`privilege-and-isolation.md`](./privilege-and-isolation.md): privileged ops behind the rootd daemon, path confinement via `realpath`, what a shell into an app does and does not change, root never acting on hop3's files (every command, not the one that prompted the fix). (ADR 046)
- [`uwsgi-daemon-management.md`](./uwsgi-daemon-management.md): Emperor / vassal lifecycle, attach-daemon env propagation, strict mode, and the two quoting layers of the daemon line.
- [`verifying-an-app-works.md`](./verifying-an-app-works.md): the ladder of false greens, why a check that cannot fail proves nothing, `[probe]` accounts, verifying effect over exit code, retry as first-class, a platform question answered by a test.
- [`web-auth-and-csrf.md`](./web-auth-and-csrf.md): cookie-based CSRF/session auth pitfalls on Litestar, rate limits, indistinguishable login failures, `Secure` cookies over plain HTTP, the framework's own idioms for forms and sessions, text from apps and URLs rendered as text; October 2026: text in a URL capped, limiter housekeeping that scaled with the attacker.
