# Plans

Where Hop3 is going, at four horizons. Each file states what it is for, so an item can be placed without argument.

| File | Horizon | Admission test |
|---|---|---|
| [`plan-0.7.x.md`](plan-0.7.x.md) | days to weeks | Does it repair or complete something a 0.7 user can already see? |
| [`plan-0.8.md`](plan-0.8.md) | September 2026 | Does it add a capability the platform is missing underneath the applications? |
| [`plan-0.9-plus.md`](plan-0.9-plus.md) | after 0.8 | Is it wanted and designed, but without a date? |
| [`parked.md`](parked.md) | not scheduled | Would it change the shape of the platform rather than extend it? |

The boundary that matters most is the last one. Everything in `parked.md` has a standing justification of its own, which is exactly why it needs a file: without one, each direction gets rediscovered, looks obviously worth doing, and takes a week before anyone asks whether it was the right week. **The default there is "not yet".**

Shipped release plans are in [`../ngi-2024/`](../ngi-2024/), kept as record.
