About this page

This is a multi-page static site deployed via Hop3's Nix builder using the static worker pattern.

The Nix derivation packages the HTML and CSS into the store. The Hop3 deployer configures nginx to serve files directly from the store path — no backend process runs for this app.

Why test this?

The static worker is a special case: it has no port, no process, and is served entirely by nginx. This page verifies that the path resolution and nginx configuration work end-to-end.
