# Nextcloud

Nextcloud is the most popular self-hosted productivity platform, combining file storage, sharing, and collaboration in one solution. It's a privacy-focused alternative to cloud services like Dropbox, Google Drive, and Microsoft 365.

## Key Features

- **File Sync & Share**: Access files from anywhere with desktop and mobile sync
- **Collaborative Editing**: Real-time document editing with Nextcloud Office
- **Calendar & Contacts**: Built-in CalDAV and CardDAV servers
- **Talk**: Video calls, chat, and screen sharing
- **Groupware**: Email, notes, tasks, and deck for project management
- **End-to-End Encryption**: Optional client-side encryption for sensitive data
- **App Ecosystem**: Hundreds of apps for extended functionality
- **Federation**: Share with users on other Nextcloud servers

## Use Cases

- Personal cloud storage and backup
- Team file sharing and collaboration
- Replacing Dropbox, Google Drive, or OneDrive
- Secure document sharing for businesses
- GDPR-compliant file storage
- Family photo and media sharing

## Why Choose Nextcloud?

Nextcloud gives you the convenience of cloud services with complete data sovereignty. You decide where your data lives and who can access it.
