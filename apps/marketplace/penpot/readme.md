# Penpot

Penpot is the first open-source design and prototyping platform purpose-built for cross-domain teams. It bridges the gap between designers and developers with native web technologies and open standards.

## Key Features

- **Vector Editing**: Professional design tools for UI/UX work
- **Real-Time Collaboration**: Work together with your team simultaneously
- **Prototyping**: Create interactive prototypes with flows and interactions
- **Components & Design Systems**: Build and maintain design systems
- **SVG-Native**: Export clean, developer-friendly SVG code
- **CSS-Ready**: Design properties map directly to CSS
- **Open Standards**: Works with standard formats, no vendor lock-in
- **Self-Hosted**: Your designs, your server, your rules

## Use Cases

- UI/UX design for web and mobile applications
- Design system creation and maintenance
- Prototyping and user testing
- Cross-functional team collaboration
- Open-source project design work
- Organizations needing design tool sovereignty

## Why Choose Penpot?

Penpot is the only open-source alternative to Figma that doesn't compromise on features. Its web-native approach means designs translate seamlessly to development.
