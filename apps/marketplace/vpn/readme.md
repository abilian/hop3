# VPN Server

A comprehensive VPN solution providing secure network access via both OpenVPN and WireGuard protocols. This package includes a web-based administration interface for easy management of users and configurations.

## Key Features

- **Dual Protocol Support**: Both OpenVPN and WireGuard protocols
- **Web Admin Interface**: Easy-to-use web UI for management
- **User Management**: Create and manage VPN users
- **Configuration Generator**: Generate client configs for all platforms
- **Multi-Platform Clients**: Support for Windows, macOS, Linux, iOS, and Android
- **Split Tunneling**: Route only specific traffic through VPN
- **Kill Switch Ready**: Compatible with client kill switch features
- **Logging & Monitoring**: Track connections and bandwidth usage

## Use Cases

- Secure remote access to home or office networks
- Privacy protection on public Wi-Fi
- Bypassing geographic restrictions
- Connecting branch offices securely
- Development and testing environments
- Secure access to self-hosted services

## Why Choose This VPN Server?

Having your own VPN server means complete control over your secure communications. No third-party VPN provider sees your traffic, and you can customize the setup to your exact needs.
