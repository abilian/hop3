# Umami

Umami is a simple, fast, privacy-focused web analytics solution. It's designed to be a lightweight alternative to Google Analytics that respects user privacy while providing the essential metrics you need to understand your website traffic.

## Key Features

- **Privacy-First**: No cookies, no personal data, GDPR compliant
- **Simple Interface**: Clean, intuitive dashboard showing what matters
- **Real-Time Data**: See visitor activity as it happens
- **Multi-Site**: Track multiple websites from one installation
- **Custom Events**: Track specific user interactions
- **Teams**: Share access with team members
- **API Access**: Programmatic access to all your data
- **Lightweight Script**: Tiny tracking script under 2KB

## Use Cases

- Website owners wanting privacy-respecting analytics
- Businesses needing GDPR-compliant tracking
- Developers monitoring application usage
- Bloggers and content creators tracking readership
- Organizations replacing Google Analytics
- Anyone wanting simple, honest metrics

## Why Choose Umami?

Umami strips analytics down to what actually matters. No complex configurations, no privacy concerns, no overwhelming dashboards—just clear insights into your website traffic.
