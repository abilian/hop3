# Ackee

Ackee is a self-hosted, privacy-focused web analytics tool built with Node.js. Unlike traditional analytics platforms that track users across the web, Ackee respects visitor privacy while still providing valuable insights about your website traffic.

## Key Features

- **Privacy-First Design**: No cookies, no personal data collection, fully GDPR compliant
- **Beautiful Dashboard**: Clean, modern interface showing page views, referrers, browsers, and more
- **Lightweight Tracking**: Minimal JavaScript tracker that won't slow down your site
- **Multi-Site Support**: Track multiple domains from a single installation
- **GraphQL API**: Programmatic access to all your analytics data
- **Self-Hosted**: Your data stays on your server, under your control

## Use Cases

- Website owners who want analytics without compromising visitor privacy
- Organizations needing GDPR-compliant traffic analysis
- Developers looking for a lightweight alternative to Google Analytics
- Teams that want to own their analytics data

## Why Choose Ackee?

Ackee proves that you don't need to sacrifice user privacy to understand your audience. It provides essential metrics like page views, visit duration, and referrer sources without tracking individual users or using cookies.
