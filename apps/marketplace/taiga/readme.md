# Taiga

Taiga is an intuitive project management platform designed for agile teams. It provides beautiful tools for Scrum and Kanban methodologies while remaining simple enough for teams just starting with agile practices.

## Key Features

- **Scrum Support**: Backlogs, sprints, user stories, and burndown charts
- **Kanban Boards**: Visual workflow management with WIP limits
- **Issue Tracking**: Track bugs and issues alongside user stories
- **Wiki**: Built-in wiki for project documentation
- **Video Conferencing**: Integrated video calls for remote teams
- **Custom Fields**: Adapt Taiga to your specific needs
- **Reporting**: Velocity, lead time, and cycle time metrics
- **Integrations**: GitHub, GitLab, Slack, and webhook support

## Use Cases

- Software development teams using Scrum or Kanban
- Product teams managing backlogs and roadmaps
- Startups coordinating multiple projects
- Remote teams needing visual collaboration
- Teams transitioning to agile methodologies
- Any project benefiting from visual task management

## Why Choose Taiga?

Taiga brings joy to project management with its beautiful design and thoughtful UX. It's powerful enough for experienced agile practitioners yet approachable for newcomers.
