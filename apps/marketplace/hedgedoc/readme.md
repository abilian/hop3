# HedgeDoc

HedgeDoc is a real-time collaborative Markdown editor that lets teams work together on documents. It combines the simplicity of Markdown with powerful collaboration features, making it ideal for technical documentation, meeting notes, and shared knowledge.

## Key Features

- **Real-Time Collaboration**: Multiple users can edit the same document simultaneously
- **Markdown Support**: Full Markdown syntax with live preview
- **Presentation Mode**: Turn documents into slideshows
- **Diagrams & Charts**: Support for Mermaid, GraphViz, and more
- **Math Equations**: LaTeX math rendering built-in
- **Version History**: Track changes and restore previous versions
- **Export Options**: Download as PDF, HTML, or plain Markdown

## Use Cases

- Team meeting notes and agendas
- Technical documentation and specifications
- Knowledge base articles
- Collaborative writing and editing
- Presentation creation
- Educational materials and tutorials

## Why Choose HedgeDoc?

HedgeDoc makes collaborative writing effortless. Its Markdown-first approach appeals to developers and technical teams, while the live preview keeps content accessible to everyone.
