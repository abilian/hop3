# Radicale

Radicale is a small but powerful CalDAV (calendars, to-do lists) and CardDAV (contacts) server. It's designed to be simple to use and configure while providing essential sync capabilities for personal information management.

## Key Features

- **CalDAV Support**: Sync calendars and to-do lists across devices
- **CardDAV Support**: Sync contacts across devices
- **Simple Setup**: Works out of the box with minimal configuration
- **File-Based Storage**: No database required, easy to backup
- **Multi-User**: Support for multiple users with authentication
- **HTTPS Ready**: Built-in HTTPS support
- **Lightweight**: Minimal resource usage
- **Standards Compliant**: Works with any CalDAV/CardDAV client

## Use Cases

- Personal calendar and contact synchronization
- Family calendar sharing
- Small team scheduling
- Self-hosted alternative to iCloud or Google contacts
- Privacy-focused PIM (Personal Information Management)
- Simple appointment and task management

## Why Choose Radicale?

Radicale does one thing exceptionally well: syncing calendars and contacts. Its simplicity makes it reliable and easy to maintain, perfect for those who want sync without complexity.
