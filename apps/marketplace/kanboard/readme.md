# Kanboard

Kanboard is a free and open-source Kanban project management software. It focuses on simplicity and minimalism, providing just the features you need to visualize your work and manage tasks effectively.

## Key Features

- **Kanban Boards**: Visual task management with drag-and-drop cards
- **Swimlanes**: Organize tasks into horizontal categories
- **Task Management**: Due dates, priorities, categories, and custom fields
- **Time Tracking**: Built-in time tracking for tasks
- **Automatic Actions**: Trigger actions based on events
- **Multiple Projects**: Manage unlimited projects and boards
- **Search & Filters**: Powerful search with saved filters
- **Plugins**: Extend functionality with community plugins

## Use Cases

- Personal task management and to-do lists
- Team project tracking
- Software development workflows
- Content creation pipelines
- Support ticket management
- Any workflow that benefits from visual organization

## Why Choose Kanboard?

Kanboard embraces the Unix philosophy: do one thing well. It's a focused tool that excels at Kanban-style project management without the bloat of larger project management suites.
